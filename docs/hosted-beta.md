# Hosted beta implementation and launch record

Status: implementation under verification; public registration is not released.

## Runtime

Next.js exports static pages. Cloudflare Pages Functions proxy only `/api/v1/*`
to FastAPI, forwarding session cookies and a server-only proxy secret. Render
runs one Python service with a small PostgreSQL pool. Neon is the authoritative
store. Legacy portfolio and holding links redirect to query-based static pages.

`render.yaml` explicitly selects Free in Frankfurt and disables signup. There is
no paid fallback, local inference, keep-alive job, or automatic plan upgrade.
Set production server secrets using provider secret storage, never browser build
variables. The Pages function needs `LOKIFI_API_ORIGIN` and `LOKIFI_PROXY_SECRET`.
The API reads the `LOKIFI_` settings documented in `lokifi/config.py`.

## Assistant and accounts

Conversations, messages, runs, proposals and quota reservations live in PostgreSQL.
The selected portfolio is disclosed before first use; verified email and consent
are required. Writes use separately confirmed, expiring proposals with ownership
and version checks. Duplicate message IDs do not invoke inference again.
Chat deletion preserves anonymous quota accounting. History expires after 30 days.

Groq uses only `openai/gpt-oss-120b`. The live Free-account tool call passed.
Browser search also returned HTTP 200, but a single whitepaper lookup consumed
78,739 tokens, including 78,333 prompt tokens generated by provider browsing.
Research remains disabled: the current search interface does not establish a
safe reservation bound for the 160,000-token daily application ceiling.

Turnstile is checked server-side against the expected hostname and action.
Verification and recovery links are single-use, hashed in storage, and carried
in URL fragments. Password recovery revokes sessions. Resend sending uses a
dedicated `mail.lokifi.com` subdomain; existing root mail records are preserved.

## Evidence recorded during implementation

- `npm run verify`: 42 PostgreSQL tests, API contract, lint, type checks, static
  production build and npm dependency audit passed (two upstream deprecation warnings).
- Desktop/mobile browser suite: eight checks passed against isolated local test
  services, including portfolio persistence, CSV, unavailable states and BTC autofill.
- `backup.py --restore-test`: all table counts and content hashes matched.
- Neon Free Frankfurt connection verified; remote database initially empty.
- Cloudflare Workers Free and Groq Free verified in account dashboards.
- Render Hobby has no card on file; service Free activation still needs verification.
- Resend domain verified; delivery requires a scoped sending credential and a live test.
- Groq inference zero-data-retention enabled; Resend transport TLS enforced.

## Required before release

Complete remote deployment, source-data migration and session invalidation,
Assistant desktop/mobile and live-provider journeys, email delivery/recovery,
Turnstile real-token/replay checks, support contact, canonical domain redirects,
and remote operation with local servers stopped. Local tests do not establish
that these release checks pass. Keep signup disabled until they do.

## Rollback

Disable signup and AI first if account or quota checks fail. Preserve the local
backup and source checkout. Roll back Pages to its prior verified deployment and
Render to the matching commit; do not downgrade or truncate the database to roll
back code. Preserve hosted data before any schema recovery. Before a public
cutover the root email records must remain unchanged.
