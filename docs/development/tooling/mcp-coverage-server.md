# Lokifi Coverage MCP Server

**Status**: ✅ Production Ready
**Purpose**: Provides real-time test coverage data access for AI assistants via Model Context Protocol

## Quick Start

### 1. Install Dependencies

```powershell
cd tools
npm install
```

### 2. Configure VS Code

Add to `.vscode/settings.json`:

```json
{
  "github.copilot.chat.mcpServers": {
    "lokifi-coverage": {
      "command": "node",
      "args": ["${workspaceFolder}/tools/mcp-coverage-server.js"]
    }
  }
}
```

### 3. Restart VS Code

Reload VS Code to activate the MCP server.

### 4. Test the Server

Ask Copilot:
- "What's my current test coverage?"
- "Which files have low coverage?"
- "Show me coverage trends"
- "Is my coverage meeting thresholds?"

## Available Tools

### 1. `get_coverage_summary`
Get current coverage metrics with test counts and threshold status.

**Example Query**: "What's my current coverage?"

**Returns**:
```json
{
  "summary": {
    "statements": 11.72,
    "branches": 89.36,
    "functions": 80.63,
    "lines": 11.72
  },
  "tests": {
    "passing": 150,
    "failing": 0,
    "total": 150
  },
  "passingThresholds": {
    "frontend": true,
    "overall": false
  }
}
```

### 2. `get_low_coverage_files`
List files below coverage threshold (default 80%).

**Example Query**: "Which files need more tests?"

**Parameters**:
- `threshold` (optional): Coverage percentage (default: 80)

**Returns**: Top 20 files with lowest coverage

### 3. `get_coverage_trends`
Compare current coverage with historical data.

**Example Query**: "Has coverage improved?"

**Returns**: Coverage changes over time

### 4. `get_file_coverage`
Get detailed coverage for a specific file.

**Example Query**: "Show coverage for portfolioStore"

**Parameters**:
- `filePath` (required): Full or partial file path

**Returns**: Line-by-line coverage with uncovered lines

### 5. `check_coverage_thresholds`
Check if coverage meets configured thresholds.

**Example Query**: "Are we meeting coverage thresholds?"

**Returns**: Pass/fail status for each metric

## Configuration

### Coverage Thresholds

Thresholds are defined in `mcp-coverage-server.js`:

```javascript
const THRESHOLDS = {
  frontend: {
    statements: 10,
    branches: 10,
    functions: 10,
    lines: 10,
  },
  backend: {
    statements: 80,
    branches: 80,
    functions: 80,
    lines: 80,
  },
  overall: 20,
};
```

### Coverage Data Source

Server reads from: `apps/frontend/coverage-dashboard/data.json`

Generated by: `npm run test:coverage` (frontend)

## Troubleshooting

### "Coverage data not found"
**Solution**: Run tests first:
```powershell
cd apps/frontend
npm run test:coverage
```

### MCP Server Not Responding
**Solutions**:
1. Check VS Code settings.json syntax
2. Restart VS Code (Reload Window)
3. Check Node.js version (>=18.0.0 required)
4. Verify MCP SDK installed: `cd tools && npm list @modelcontextprotocol/sdk`

### "No file-level coverage data"
**Cause**: Coverage dashboard data.json doesn't include file details
**Solution**: Run full coverage report: `npm run test:coverage`

## Maintenance

### Update Coverage Data
Coverage data updates automatically when you run:
```powershell
npm run test:coverage
```

### Update Thresholds
Edit `THRESHOLDS` object in `mcp-coverage-server.js`

### Add New Tools
1. Add tool definition to `ListToolsRequestSchema` handler
2. Implement handler in `CallToolRequestSchema` switch statement
3. Update this README with new tool documentation
