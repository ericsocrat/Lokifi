# Backend Coverage Logs

**Purpose**: Pytest coverage reports in JSON and HTML formats.

## Current Files

- **coverage.json** (707 KB) - Machine-readable coverage report
  - Generated by: `pytest --cov --cov-report=json`
  - Contains: Line coverage, branch coverage, file-by-file metrics
  - Use for: CI/CD coverage tracking, automated reports

- **htmlcov/** (16.75 MB, 311 files) - Interactive HTML coverage report
  - Generated by: `pytest --cov --cov-report=html`
  - Open: `htmlcov/index.html` in browser
  - Features: Line-by-line coverage highlighting, branch coverage, file navigation

## Usage

```bash
# Generate both JSON and HTML reports
pytest --cov --cov-report=html --cov-report=json

# Generate with specific coverage target
pytest --cov=app --cov-report=html --cov-report=json

# View HTML report
start htmlcov/index.html  # Windows
open htmlcov/index.html   # macOS
xdg-open htmlcov/index.html  # Linux
```
